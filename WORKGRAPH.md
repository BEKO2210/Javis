# WorkGraph

WorkGraph turns Codex/Claude sessions into reusable journey memory, evals, traps, and skills.

## Start

```bash
workgraph start
```

## Stop

```bash
workgraph stop
```

## Reuse A Prior Pattern

```bash
workgraph reuse "graph visualization"
```

## Export A Skill

```bash
workgraph skill export "Force graph visualization" . --query "graph visualization UI"
```
