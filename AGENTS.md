## WorkGraph

If the user asks to start WorkGraph, listen to the session, reuse prior work, or export a reusable skill, use:

- `workgraph start codex`
- `workgraph status .`
- `workgraph reuse "<query>"`
- `workgraph skill export "<name>" . --query "<query>"`

The UI runs at `http://127.0.0.1:8787` after engagement.
